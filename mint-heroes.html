◈ mint the heroes ◈

a hero exists only once a voucher is signed and redeemed — there is no owner mint
1

Sign vouchers with the claim-signer wallet. This is a signature, not a transaction: free, no gas, nothing on-chain. Each voucher names one card, one recipient and an expiry.

2

Redeem them. claimHero is permissionless — anyone holding a valid voucher can send it, which is the point: the studio never pays gas for a collector's claim. One transaction per card.

3

Vouchers survive a wallet switch (stored locally, and downloadable), so you can sign as the signer and redeem as anyone.
